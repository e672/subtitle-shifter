#  subtitle-shifter
## Explanation
I couldnt A basic program for incorrect subtitles.That shifts all of the subtitle texts with given miliseconds.If the number below the zero it shifts back in time otherwise forward.I couldn't find a solution for when i watching videos with out of synced subtitles and that made me write this.
 
# Installation
No installation required
#### Clone the repository:
1. git clone https://github.com/e.672/subtitle-shifter.git
2. add your txt file that contains your subtitle to the directory
3. change the path name(example:input.txt) with your txt file and change the second parameter subFix() function down at the end of the code and run.
